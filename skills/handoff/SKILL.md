# Handoff

Adapted from mattpocock/skills handoff for a time-limited hackathon. Exam rules and task instructions prevail.

Write a concise handoff inside a persistent task workspace path that the next session can access. Do not use a transient OS temp directory. Include the current objective and completion criteria, confirmed rules and sources, key decisions, changed files, latest actual verification, reproducible failures, attempted approaches and prioritized next action. Mark assumptions and unverified results; reference existing artifacts rather than duplicating them. Exclude secrets and unnecessary personal information.

Verify the file exists and report its path. The next session must check the actual files and evidence rather than blindly trusting the handoff.
